سناب مذكر - APK (Capacitor + GitHub Actions)

1. ارفع كل الملفات لريبو جديد فـ GitHub (فرع main).
2. الـ workflow الفعلي هو .github/workflows/build-apk.yml (build-apk.yml لي برا نسخة منو).
3. Actions > Build Android APK > Run workflow. كيدوز 5-8 دقايق.
4. نزّل snap-mudhakkir-apk من Artifacts، فك الضغط، وثبّت app-debug.apk.
